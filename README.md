# CASE STUDY 2
# ỨNG DỤNG QUẢN LÝ VÀ GIAO CÔNG VIỆC NHÓM

## Thông tin sinh viên
- MSSV: KHMT2411019
- Họ và tên: Lâm Duy Thịnh

## Công nghệ sử dụng
- Frontend: Flutter
- Backend: Node.js, Express.js
- Database: MongoDB Atlas

## Cấu trúc dự án
- api/: Backend Node.js và Express REST API
- task_manager/: Ứng dụng Flutter

## Khởi chạy Backend
1. Mở Terminal tại thư mục api.
2. Chạy npm install.
3. Tạo file .env từ .env.example và cấu hình thông tin MongoDB, JWT.
4. Chạy npm run dev.

## Khởi chạy Flutter
1. Mở Terminal tại thư mục task_manager.
2. Chạy flutter pub get.
3. Khởi động Android Emulator.
4. Chạy flutter run.

## API
- Backend: http://localhost:3000/api
- Android Emulator: http://10.0.2.2:3000/api
